# Historias de Usuario

|---|---|

| HU02 | Como conductor, quiero recibir una alerta de audio cuando me acerque a un tramo peligroso, para reducir la velocidad con anticipación. |
| HU03 | Como conductor, quiero que la app funcione aunque no haya señal en la ruta, para no perder ningún evento detectado durante el trayecto. |

| HU05 | Como ciudadano, quiero ver el mapa sin registrarme ni instalar nada, para acceder a la información de forma inmediata. |
| HU06 | Como autoridad vial, quiero ver el ranking de kilómetros con más anomalías reportadas, para priorizar las intervenciones de mantenimiento con datos reales. |
| HU07 | Como autoridad vial, quiero exportar los datos de anomalías en formato GeoJSON, para trabajarlos directamente en QGIS o ArcGIS. |
| HU08 | Como administrador, quiero gestionar los accesos de las autoridades viales al panel institucional, para controlar quién puede ver qué información. |
